# VOX Image Runner Privacy Policy

Last updated: August 1, 2026

VOX Image Runner processes the prompts, reference images, generated image bytes,
and task metadata that a user chooses to submit through the extension. It uses
this data solely to operate the user-facing image-generation workflow.

## Data handled

- Prompts and aspect-ratio settings entered by the user.
- Reference images selected by the user or supplied by a connected VOX workspace.
- Generated image bytes retrieved from the user's signed-in ChatGPT session.
- Queue state, diagnostics, and download preferences stored locally in the browser.

## How data is used

The extension sends the selected prompt and reference images to ChatGPT only
when the user starts a task. When a VOX workspace is connected, generated image
bytes and task status are returned to that workspace so the corresponding
storyboard beat can be updated. The extension does not sell data, serve ads,
or use data for advertising or profiling.

## Storage and retention

Queue data, selected-reference bytes, and diagnostic logs are retained locally
only as long as needed for the active queue and recovery. Users can clear their
queue and logs from the extension. Generated assets returned to VOX are retained
according to the workspace's own policies.

## Sharing

Data is shared only with ChatGPT to perform the requested generation and, when
the user connects VOX, with that VOX workspace to save the requested result.

## Contact

For support or privacy questions, contact the publisher through the support
email listed in the Chrome Web Store listing.
