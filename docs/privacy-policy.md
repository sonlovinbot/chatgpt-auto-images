# ChatGPT Image Automation Privacy Policy

Last updated: August 1, 2026

ChatGPT Image Automation processes the prompts, reference images, generated images,
and task details that you choose to use with the extension. This information is used
only to provide the image-generation workflow you start.

## Data handled

- Prompts and aspect-ratio settings entered by the user.
- Reference images selected by the user.
- Generated image bytes retrieved from the user's signed-in ChatGPT session.
- Queue state, diagnostics, and download preferences stored locally in the browser.

## How data is used

The extension sends a selected prompt and any selected reference images to
ChatGPT only when you start a task. It does not sell data, show ads, or use
data for advertising or profiling.

## Storage and retention

Queue data, selected-reference bytes, and diagnostic logs are retained locally
only as long as needed for the active queue and recovery. You can clear the
queue and logs from the extension.

## Sharing

Data is shared only with ChatGPT to perform the image generation you requested.

## Contact

For support or privacy questions, contact the publisher through the Chrome Web
Store listing.
